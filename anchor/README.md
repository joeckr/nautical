## Nautical Anchor

Nautical Anchor is the core REST API for the Nautical Stack.

Facilitates communication between the Nautical Stack and the Nautical CLI.

Connects to container sources (e.g. Docker, Kubernetes)

Connects to logging data sources (e.g. Opensearch, Loki)

Facilitates API access for Beacon (Frontend)

Has it's own database to save developer information and previous sessions.
