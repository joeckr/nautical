## Nautical Sonde

Sonde is a probe used in Marine biology in order to collect information about the environment. Similarly this Sonde is a probe used in the Nautical Stack to monitor your containers and logs. Sonde is planned to do the following:

- Monitor the health of your containers
- Monitor logs and creates reports for:
  - Repeated errors 
  - Potentially malicious activity
  - Recommendations for improving:
    - Security
    - Performance
    - Reliability
    - Log formatting
